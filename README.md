# Bimestral

# descrpcion

Mi proyecto consiste en crear una página web para mi carrera como cantautor, usando el nombre artístico **ZØREN**. En ella mostraré mi música, eventos, fotos y videos. También tendrá un espacio de contacto y una base de datos para organizar la información del sitio.

### problema 

Como cantautor independiente, puedo tener dificultades para dar a conocer mi música y mantener toda mi información artística organizada. Si dependo solamente de redes sociales y otras plataformas, las personas pueden tener que buscar mis canciones, eventos y demás contenido en diferentes lugares.

### causas

* No tener un sitio web propio.
* Tener la información repartida en diferentes plataformas.
* Depender de las redes sociales para promocionar mi música.
* No tener un lugar donde reunir mis canciones, eventos, fotos y videos.
* Tener pocas opciones de contacto directo con las personas interesadas en mi música.

### consecuencias 

* Las personas pueden tener dificultades para encontrar mi música.
* Mis nuevos lanzamientos pueden tener menos visibilidad.
* Se pueden perder oportunidades para realizar presentaciones.
* Los seguidores pueden tener dificultades para encontrar información sobre mis eventos.
* Puede ser más complicado recibir mensajes de personas interesadas en mi trabajo.

### aporte 

Mi aporte será crear un sitio web oficial para mi carrera como cantautor. En él podré reunir mi música, eventos, fotografías, videos y formas de contacto en un solo lugar.

Con esto quiero que las personas puedan conocer más fácilmente mi trabajo como ZØREN y encontrar toda la información relacionada con mi carrera musical.

### solucion 

La solución será desarrollar una página web oficial para ZØREN. En ella los visitantes podrán conocer mis canciones y álbumes, consultar mis próximos eventos, ver fotografías y videos y enviarme mensajes.

También tendrá un sistema de registro e inicio de sesión para los usuarios y una parte de administración para poder actualizar la información de la página.
